# Share presets in Noice-Fork

Open **Presets**, select a preset’s menu, and tap **Share**. Share the complete link, including everything after `#`. That part carries the preset name and sound settings, not recordings. A browser sends the page address to GitHub, but not the fragment.

To import, copy the original link and open **Presets → Import preset link** in Noice-Fork. Paste it and confirm. Import works offline and does not start playback or replace your saved presets. Old Noice V1 links still work; Noice V2 links use a different format.

To contribute a community preset, [open an issue](https://github.com/LRQ3000/Noice-Fork/issues) with the link and a short description of the mix.
